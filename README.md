# Mainframe

Mainframe is the video layer for agent work. This repository ships the
`share-video` skill for agents that support the open agent skills ecosystem.

## Install

```sh
npx skills add mainframecomputer/mainframe-plugins
```

To preview the available skills without installing:

```sh
npx skills add mainframecomputer/mainframe-plugins --list
```

## Skill

- `share-video` — generate or share a short Mainframe video when a demo,
  walkthrough, PR recap, async update, visual bug report, or durable handoff
  would be clearer than another chat message.

The skill lives at `skills/share-video/SKILL.md`.
